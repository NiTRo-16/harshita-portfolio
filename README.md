# Harshita Gupta: Portfolio

Personal portfolio of **Harshita Gupta**, B.Tech CSE (AI & ML) student at the Institute of Engineering & Science, IPS Academy, Indore.

A single-page website built with plain HTML, CSS and JavaScript. No build step and no dependencies.

## Features

- Blush-pink glass bento layout over slowly drifting color blobs
- Animated glass orb emblem with rotating line-art lotus rings
- Auto-cycling project accordion with animated previews:
  - Dementia Patient Support Platform
  - Expense Tracker
  - Hotel Management System
- Cursor spotlight on tiles, click-to-copy email, and animated education rings
- Responsive, and respects reduced-motion settings

## Run locally

Open `index.html` in any browser.

## Deploy

**GitHub Pages:** Settings → Pages → Source: `main` branch, `/ (root)`.
